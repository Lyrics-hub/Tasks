## 三、学习内容
### 1.基本概念引入：*什么是GitHub?我能利用GitHub干什么？*
#### Git:一款版本控制软件，它记录了每次修改文件时的状态，支持同时建立修改分支，最后合并分支。
#### GitHub：一个国外开源程序协作平台，用来存放Git生成的文件和修改信息。
#### 2.具体操作：*概念转化为实践*
- （1）从Git官网下载安装Git软件
- （2）初次使用需要进行账户配置，生成并安装了SSH Key：
    - 在Git终端里，按照教程输入指令生成密钥；
    - 复制公钥，复制到GitHub网站里的SSH设置里，完成安装。
- （3）建立第一个仓库，流程如下：
    - 在终端输入git clone 仓库地址，并把仓库下载到了电脑D盘
- （4）编辑文件
    - 进入仓库Tasks在D盘中的文件夹，建立.md格式的笔记；
    - 使用VS Code 打开并编辑。
- （5）同步到GitHub，依次在终端输入：
    - git add .（提交修改）
    - git commit -m "修改说明文字”
    - git push
